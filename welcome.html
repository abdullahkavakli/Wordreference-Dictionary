Quick start

1. Choose your language pair

Pick the language you want English translated to — Spanish, French, German, Turkish, and 14 others — on the settings page.

2. Look up any word, anywhere

Four ways to reach a translation, whichever fits your flow:

Alt + Z Open the dictionary popup. Type or paste any word. Alt + X Select text on any web page, then press to show an in-page translation bubble. Alt + Q Same as Alt + X — an alternate binding for keyboard layouts where Alt + X is taken. Alt + double-click Hold Alt and double-click a word to translate it right where it sits. Right-click Select a word, right-click, then choose WordReference: '…' to open the full result in a new tab.

3. Save what you learn

Star any word from the popup or in-page bubble to add it to your favorites. Manage and export the list to Excel from the settings page — perfect for vocabulary review.
