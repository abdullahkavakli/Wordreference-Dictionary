Privacy Policy for WordReference Dictionary

Effective date: April 26, 2026

WordReference Dictionary is a Chrome extension that helps users look up WordReference translations, definitions, IPA transcriptions, and pronunciation audio directly from the browser.

Data the Extension Handles

  • Selected text or manually typed lookup text.
  • Extension preferences, such as language pair, IPA dialect, shortcut settings, modifier key, and PDF viewer setting.
  • Favorites saved by the user.

How Data Is Used

Selected or typed lookup text is used only to fetch matching dictionary results from WordReference.com. These results are shown in the extension popup or in-page translation bubble.

Preferences are stored using chrome.storage.sync. Favorites are stored using chrome.storage.local. The extension does not send preferences or favorites to the developer or to any custom backend.

PDF Support

If the optional PDF viewer is enabled, PDF files may be opened in the extension's built-in viewer so users can look up selected words inside PDFs. PDF rendering is handled locally in the browser using Mozilla PDF.js. The extension does not upload PDF content to the developer or to any custom server.

Third Parties

Lookup requests are sent directly to WordReference.com. WordReference.com may receive the searched word or phrase as part of the lookup URL or request. If the user clicks a Google search fallback link, that search opens on Google.

Data Collection

The extension does not collect personal information, health information, financial information, authentication information, location, browsing history, user activity analytics, or personal communications.

The extension does not use analytics, advertising, tracking, telemetry, or a custom backend.

Data Sharing

The developer does not sell, rent, share, or transfer user data. No user data is sent to the developer.
